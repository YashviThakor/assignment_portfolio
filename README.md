This is the official portfolio website for Cristian Munoz, a Product Designer. The site features a dark, high-contrast, and visually impactful design to showcase skills, projects, and professional metrics.

## ✨ Features

* **Bold Hero Section:** Large, gradient typography for maximum visual impact.
* **Key Metrics:** Dedicated section highlighting professional statistics (Upwork Job Success Score, Figma Duplicates, etc.).
* **8-Project Portfolio Grid:** A clean, responsive grid showcasing key design works with relevant tech tags (UX Design, Angular, JavaScript).
* **Interactive Skills Showcase:** Skill cards featuring progress indicators and descriptions for core competencies like UI/UX Design and Prototyping.
* **Client Testimonial:** A dedicated section for social proof and client feedback.
* **Responsive Design:** Optimized for desktop, tablet, and mobile viewing using Tailwind CSS breakpoints.

## 🛠️ Tech Stack

This project is a static website built with modern web technologies:

* **HTML5:** Structure and content.
* **Tailwind CSS:** Utility-first framework for rapid and responsive styling.
* **Poppins:** Primary web font for modern typography.
* **Custom CSS:** Minimal custom styles primarily for the unique gradient text effect.

## 🚀 Getting Started

Since this is a static HTML project, you do not need a build process to view it.

### Prerequisites

You only need a modern web browser to view the project.

### Installation

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/YashviThakor/assignment_portfolio.git](https://github.com/YashviThakor/assignment_portfolio.git)
    ```

2.  **Navigate to the Project Directory:**
    ```bash
    cd assignment_portfolio
    ```

3.  **Open in Browser:**
    Locate the `index.html` file in the project directory and open it directly in your web browser (e.g., Google Chrome, Firefox).

## 💡 Code Structure

The entire website structure and styling are contained within a single file:

* **`index.html`:** Contains all HTML structure, inline Tailwind CSS utility classes, and custom `<style>` blocks.
